# [L4D.1&2] Glows (v. customize 4.4) FINAL

Basado en el diseño de R1KO, editado por vℓα∂ιмιr: [L4d2] Flashlight + Glows + Disco - 2.0

---

## DESCRIPCIÓN:
Gestiona y personaliza el aura de tu personaje con el color de tu preferencia.

PROPIEDADES:
-  Soporte para agregar colores.
- Compatible con Lux's Model Changer(LMC) y Hats.
- Cookies.
- Rainbow Color.
- etc...

GLOBALES:

## BUGS:
  * Existe la posibilidad que al estar en Tercera Persona inmediatamente por 2da vez, ya sea con este u otro plugin durante el cambio de color puede generar el siguiente resultado:
<img width="1199" height="635" alt="Captura de pantalla 2026-06-18 165516" src="https://github.com/user-attachments/assets/0f64ce43-544b-42f9-b396-9fd009216113" />

Curarse o cambiarse el color sin interrupciones soluciona este problema.
Evite cambios bruscos o rápidos con otros plugins con Tercera Persona.
**Espere a que termine el efecto de Tercera Persona y recién elija otro color.**
